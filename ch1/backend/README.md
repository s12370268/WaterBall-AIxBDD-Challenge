# 後端服務（預留）

此目錄預留給未來獨立的 API 後端，目前沒有執行中的後端服務，也尚未選定框架或資料庫。

建議未來將登入驗證、商品 CRUD、照片儲存與訂單 API 實作於 `src/`，並由後端持久保存資料與檢查管理權限。確定技術後再加入對應的套件設定、測試、資料庫遷移及環境變數範本。

`frontend/src/admin/` 是管理員在瀏覽器操作的前端介面，仍屬於前端。`frontend/scripts/dev.mjs` 僅為靜態開發伺服器。

目前前端的 `src/catalog.js` 與 `src/admin/auth.js` 分別集中商品儲存與示範登入邏輯，未來可從這些邊界接入 API。現階段資料仍存於瀏覽器，不會自動同步到此目錄。
