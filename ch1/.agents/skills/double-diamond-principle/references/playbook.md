# 方法選擇與可複製模板

以下模板是本 skill 的實務延伸。依可取得資料調整，不把空白填成虛構發現。

## 依未知選方法

| 尚未理解的事 | 合適方法 | 可得到的學習 | 常見限制 |
|---|---|---|---|
| 人實際怎麼完成任務 | 情境訪談、觀察、日誌 | 行為、情境及變通方式 | 自述與行為可能不同；樣本有限 |
| 哪裡發生障礙 | 旅程圖、事件資料、客服紀錄 | 接觸點、頻率與斷點 | 紀錄缺漏；無法直接證明原因 |
| 哪個問題值得先處理 | 主題分組、證據回顧、設計簡報 | 問題取捨與範圍 | 多數意見不等於證據充分 |
| 有哪些不同介入方式 | 個別發想後共創、跨領域參考 | 候選方案與假設 | 工作坊共識不是需求驗證 |
| 人是否理解並能完成任務 | 紙本／可點擊原型、角色扮演 | 理解、操作障礙及服務接續 | 不直接證明長期成效 |
| 真實情境是否改善結果 | 小規模試行、適當對照 | 結果與營運影響 | 須注意混淆變項與倫理限制 |

不要把訪談預設人數或兩週試行說成統計保證；按異質性、決策風險、可接觸對象與學習目標提出招募理由。

## 90 分鐘快速工作坊範例

此時間配置是示意，不是完成研究的承諾。

| 時間 | 活動 | 產物 |
|---|---|---|
| 0–10 分 | 明確決策、角色與限制 | 範圍及共同詞彙 |
| 10–30 分 | 展示現有證據、個別補充反例 | 證據／未知表 |
| 30–45 分 | 聚類、比較候選問題 | 暫定問題與 HMW |
| 45–65 分 | 先個別發想，再跨角色交流 | 不同介入方案 |
| 65–80 分 | 用事先說明的判準選原型 | 方案與假設 |
| 80–90 分 | 寫實驗卡及承接角色 | 下一步與回退規則 |
