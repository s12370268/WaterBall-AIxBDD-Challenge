## 核心框架

來源：[Framework for Innovation — Design Council](https://www.designcouncil.org.uk/resources/framework-for-innovation/)

雙鑽石讓團隊先拓展問題理解再聚焦挑戰，接著拓展解法再篩選。四階段為 Discover、Define、Develop、Deliver。原文強調過程可以往返，早期原型也能用來探索問題。它不是把工作切成四個不得回頭的關卡。

創新框架還涵蓋四個原則：以人為本、以視覺且包容的方式溝通、合作共創，以及反覆迭代。方法庫以 Explore、Shape、Build 組織；這三類不是四階段的更名。領導與參與關係也是實踐條件。

對 skill 的啟示：除了階段表，還需要參與安排、證據可追溯性與回饋決策。具體證據標籤、方案數、實驗卡及轉階判斷是本 skill 的設計選擇，並非官方硬性要求。

## 模型的定位與歷史

來源：[The Double Diamond — Design Council](https://www.designcouncil.org.uk/resources/the-double-diamond/)

此模型用簡明圖像描述設計與創新，不綁定特定工具。官方歷史記載團隊於 2003 年開始整理共通設計流程；Framework for Innovation 頁面將正式推出記為 2004 年。區分整理成形與推出年份，可避免把它們誤寫成互斥主張。

延伸閱讀：[History of the Double Diamond — Design Council](https://www.designcouncil.org.uk/resources/the-double-diamond/history-of-the-double-diamond/)。歷史頁也說明團隊比較內外部設計方法，並於 2004 年開始在會議與簡報中分享模型；其貢獻包含整理、命名與傳播既有設計思想。

它是溝通框架，並不表示四階段自動保證創新或成效。Deliver 包含小規模試驗、排除不適合的方案及改進可行方向；不能只譯成「完成開發並上線」。

## 方法層的延伸

來源：[Design methods for developing services — Design Council／Technology Strategy Board](https://www.designcouncil.org.uk/fileadmin/uploads/dc/Documents/DesignCouncil_Design%2520methods%2520for%2520developing%2520services.pdf)

這份服務設計入門指南將旅程、日誌、服務體驗與觀察放入探索；將人物誌、設計簡報等放入定義；用服務藍圖、體驗原型與商業模式協助發展，並在交付安排測試、推出與回饋。方法需依任務與資源調整，不能機械套用。

本 skill 因此依「要降低什麼未知」選方法。沒有研究時，人物誌只能當作待驗證假設；旅程圖也應標示哪些接觸點有資料支持。官方早期指南偏重推出服務，應與當前框架強調的小規模測試、持續改善一起理解。

## 系統性延伸

來源：[Systemic Design Framework — Design Council](https://www.designcouncil.org.uk/resources/systemic-design-framework/)

當挑戰牽涉跨部門、社會與環境關係時，官方延伸保留發散與收斂的思想，改用 Explore、Reframe、Create、Catalyse。它也關注過程周圍的願景、關係、領導／敘事與持續行動，並搭配工具組。

對 skill 的啟示：局部產品指標未必反映整體結果。需要記錄誰承擔成本、誰有決策權、有哪些依賴及長期副作用。此系統視角是延伸，不應把上述四個名稱冒充雙鑽石原始四階段。

## 實務整合與界線

以下是本 skill 的延伸，不是官方逐項規定：

- HMW 用來保持問題開放，不能取代有證據的問題陳述。
- 在方案比較前訂判準，減少用既定喜好反推評分的偏差。
- 在測試前訂成功、停止與回退條件，使反證有機會改變決策。
- 可將已驗證的使用者需求再轉為需求規格或驗收情境；雙鑽石本身不取代工程測試、專業審查或產品維運。
- 時限短時縮小學習範圍；一次工作坊只能產出假設或初步共識，不能被稱為完成使用者驗證。

## 適用條件、規則與例外

| 條件 | 採用方式或例外 | 依據及性質 |
|---|---|---|
| 挑戰仍模糊，或需求可能被方案偏好掩蓋 | 先探索情境，再暫定問題 | 核心框架 Discover／Define；操作建議 |
| 問題已有可信研究，現在需比較解法 | 沿用既有證據，聚焦第二鑽石 | 方法可依任務調整；本 skill 的比例原則 |
| 新證據否定既有理解 | 可回到前面，探索中也能測原型 | 核心框架的非線性說明；官方原則 |
| 方法被當成固定儀式 | 依產出與資源調整深度，避免盲目照做 | 方法指南 PDF 第 6 頁；官方方法指引 |
| 跨部門與環境依賴影響成效 | 補充系統性分析，不把局部指標當整體結果 | 系統性延伸；後半為本 skill 的解讀 |
| 任務只是明確的小修改，或使用者指定方案不可變 | 使用最小必要驗證，不強迫重新研究 | 本 skill 的適用界線，非官方排除清單 |
| 資料不足或只有一次工作坊 | 交付暫定框架與蒐證計畫，不宣稱已驗證 | 本 skill 的證據誠信規則 |
